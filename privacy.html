Privacy Policy

Application: Auto Post TikTok · Last updated: 21 August 2026

1. Scope

Auto Post TikTok ("the Application") is a private, single-user tool operated solely by its author on the author's own computer. It has no other users and collects no data from anyone other than its author.

2. What the Application accesses

When the author authorizes the Application through TikTok's official OAuth flow, the Application receives:

  • An OAuth access token and refresh token for the author's own TikTok account
  • The account's open_id and basic public profile information (username, display name, avatar)
  • The account's permitted privacy-level options, which TikTok requires the Application to read before publishing

The Application requests only the scopes user.info.basic, video.upload, and video.publish.

3. Where data is stored

All tokens are stored in a single local file on the author's own computer. Nothing is transmitted to, stored on, or processed by any server operated by the author or any third party. The Application has no backend, no database, and no analytics.

4. What is shared

Nothing. No data is sold, rented, shared, or disclosed to any third party. The only network connections the Application makes are direct requests to TikTok's own official API endpoints at open.tiktokapis.com.

5. Video content

Video files are read from the author's local disk and uploaded directly to TikTok. No copy is retained anywhere else, and no copy passes through any intermediary service.

6. Retention and deletion

Tokens are retained only for as long as the Application is in use. They can be destroyed at any time by deleting the local token file. Authorization can be revoked independently at any time from the TikTok account's connected-apps settings, which immediately invalidates all issued tokens.

7. Children

The Application is not directed at, and is not usable by, anyone under 18.

8. Changes

This policy may be updated from time to time. The version published at this URL is always the version in force.
