Auto Post TikTok

A personal desktop tool for scheduling and publishing my own videos to my own TikTok account.

What it does

Auto Post TikTok is a small program that runs on my own computer. It takes video files I have produced myself, together with the captions I wrote for them, and publishes them to my own TikTok account through the official TikTok Content Posting API.

How it works

  • I authorize the tool once, on my own account, through TikTok's official OAuth flow.
  • Before every post, the tool reads the privacy levels my account permits and shows me the video, the caption, and the target account name.
  • The video file is uploaded directly from my local disk to TikTok. It does not pass through any other server.

Scope of use

This is a single-user tool. It is not offered to the public, it has no other users, and it never publishes content belonging to anyone else.

Privacy

No data is collected, stored remotely, or shared with anyone. Authorization tokens live only in a file on my own computer, and the only network calls the tool makes are to TikTok's own API.
